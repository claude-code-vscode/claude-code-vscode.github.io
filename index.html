What the sidebar adds over the terminal

The original Claude Code was a terminal program, and the extension is a genuine editor integration rather than a terminal in a panel. Anthropic's description is specific: Claude knows about your current file and your text selection, and proposes changes directly inside your editor window. Its announcement adds the mechanism, a dedicated sidebar panel showing changes in real time with inline diffs. That is the practical difference. In a terminal you read a patch and imagine it applied; in the sidebar you see it against the file you were already looking at. If you preferred the old behaviour, it did not disappear. A setting called Claude Code: Use Terminal switches the extension back to the terminal-style experience, which is an unusually graceful way to ship a redesign.

Install requirements and what it actually costs

The Marketplace listing is published by Anthropic under the identifier anthropic.claude-code, sits in the AI category, and is marked Free. It has recorded 25,977,239 installs against 792 ratings, a ratio worth noticing before you read too much into the review score either way. The one hard requirement is VS Code 1.98.0 or higher. Installation is the standard route: open Quick Open with Ctrl+P, paste the install command from the listing, press enter. Free refers to the extension, not to the work it does. Anthropic states you use the latest Claude models with a Pro, Max, Team or Enterprise subscription, or with pay-as-you-go pricing. Neither the Marketplace page nor the extension overview quotes those rates, so check the official plan page before budgeting a team rollout.

Checkpoints, and exactly what they miss

Checkpointing is the feature that makes delegating a wide refactor reasonable. The system automatically saves your code state before each change, and you rewind by tapping Esc twice or running the /rewind command. When you rewind you choose what comes back: the code, the conversation, or both. The limitation is stated plainly by Anthropic and is easy to skip past. Checkpoints apply to Claude's edits only. They do not cover your own edits, and they do not cover bash commands, which is precisely the category of action most likely to need undoing. Anthropic's own recommendation is to use checkpoints in combination with version control rather than instead of it. Commit before you hand over a big task and the gap stops mattering.

Which features still need the command line

Anthropic is candid that the extension is not a full replacement for the CLI. Subagents, custom slash commands and MCP all work in the VS Code extension, but the overview notes some of them can only be configured through the command-line interface. So the day-to-day works in the sidebar while the setup may not. Beyond that, the documented VS Code workflow covers more session management than most people discover: referencing files and folders from the prompt box, resuming past conversations, resuming cloud sessions started on Claude.ai, checking account and usage, running multiple conversations at once, grouping sessions, choosing where Claude lives in the layout, and managing plugins. Worth reading the docs page once rather than learning those by accident six months in.

FAQ

Is the Claude Code VSCode extension free?

The extension itself is listed as Free on the VS Code Marketplace. Using it is not free in the general case: model access comes either from a Pro, Max, Team or Enterprise subscription, or from pay-as-you-go pricing. Neither rate appears on the Marketplace listing, so check the official plan page before rolling it out to a team.

What are the requirements for Claude Code VSCode?

VS Code 1.98.0 or higher is the only requirement stated on the listing. Install it through Quick Open with Ctrl+P and the install command shown on the Marketplace page, or search the AI category for the Anthropic publisher directly inside the editor's extensions panel.

Can it run terminal commands and edit files on its own?

Yes, with your permission. Anthropic describes Claude as autonomously exploring your codebase, reading and writing code, and running terminal commands with permission. Proposed changes appear inside the editor window, and the sidebar panel shows them as inline diffs before they land.

How do I undo something it did?

Checkpoints save your code state before each change. Tap Esc twice or run /rewind, then choose whether to restore the code, the conversation, or both. Note that checkpoints cover Claude's edits only, not your own edits and not bash commands, so keep using version control alongside them.

Do subagents, slash commands and MCP work in the extension?

They work, with one asterisk. Anthropic notes that these agentic features are supported in the VS Code extension, but that some of them can only be configured through the command-line interface. Expect to use the CLI for setup even if you do all your day-to-day work in the sidebar.

What if I do not have a codebase yet?

Then an editor agent has nothing to act on. Begin.sh takes a prompt, or a URL you want cloned, and returns a working static site or Expo app as a zip you download. It deliberately stops there, with no hosting, backend or authentication, which makes it a starting point rather than a platform.
